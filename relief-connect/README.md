# Relief Connect Monorepo

Apps:
- backend (Express + MongoDB + Socket.IO)
- web-dashboard (React + Vite + Tailwind + Leaflet)
- mobile (React Native + Expo)

## Quick start (dev)

### Backend
```
cd backend
cp .env.example .env
npm i
npm run dev
```

### Web Dashboard
```
cd web-dashboard
cp .env.example .env
npm i
npm run dev
```

### Mobile
```
cd mobile
npm i
npx expo start
```
